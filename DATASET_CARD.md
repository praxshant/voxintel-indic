# VoxIntel Indic Dataset Card

## Summary

The dataset supports research on noisy, code-mixed Indic speech-to-intent
classification for a banking taxonomy of ten intents plus `other`.

## Composition

The v0.3 text source contains 2,400 deterministic candidate utterances:
1,800 in-scope rows and 600 `other` rows. Each row records language, script,
mixing condition, intent, `other_type`, paraphrase cluster, intended split,
and text-generation provenance. The text is marked
`machine_reviewed_pending_human_spot_check`; it is not represented as
human-verified language data.

The v0.2 synthetic release contains 198 8 kHz mono PCM WAV files generated by
Sarvam Bulbul v3 from 98 TTS rows plus two local audio rows.

The public subset contains 1,915 IndicVoices records across Bengali, Gujarati,
Hindi, Kannada, Marathi, Tamil, and Telugu. It excludes English because the
source dataset has no English configuration. Its assignment labels are
keyword-derived weak candidates. Original annotations and speaker metadata are
retained.

## Intended use

Use the data for prototyping, controlled ablations, split validation, and
comparison of an ASR cascade with direct audio-to-intent classification. Keep
synthetic and public evaluation results separate.

## Out of scope

Do not use this dataset to claim real-world caller performance, production
readiness, demographic fairness, or superiority of direct audio classification
without a frozen, comparable evaluation.

## Known limitations

- Template-expanded v0.3 text requires human spot review.
- Bulbul audio can contain TTS artefacts and does not represent natural callers.
- IndicVoices assignment labels are weak and imbalanced; `block_card` has only
  five current candidate records.
- Keyword filtering can retain general banking discussion rather than an
  actionable caller intent.
- No real-speaker test set is collected or required.
- Licensing and attribution requirements for IndicVoices (CC BY 4.0) must be
  preserved when distributing derived data.
